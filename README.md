## What it is

sididy-mesh is a deterministic, zero-dependency estate tool. The wire-up — every estate organ running as one live mesh: nodes (each a wisp folding into fall-remember, kappa-gated, liveness-watched, budget-governed) bound by LIGHT, reporting whether the whole is alive. It never throws on hostile input and
produces the same result on every machine.

## API

- `LiveMesh`
- `LiveNode`
- `default`
